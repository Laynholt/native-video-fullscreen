# Native Video Fullscreen

<img src="assets/icon.png" width="80" alt="Логотип Native Video Fullscreen">

Скрипт для Safari на iPhone. Добавляет кнопку **⛶** поверх видео и открывает его в системном полноэкранном плеере iOS с текущей позиции.

## Установка на iPhone

[![Установить скрипт](assets/install.svg)](https://github.com/Laynholt/native-video-fullscreen/releases/latest/download/native-video-fullscreen.user.js)

1. Установите [Userscripts из App Store](https://apps.apple.com/app/userscripts/id1463298887). Откройте приложение и выберите папку для скриптов.
2. Включите расширение Userscripts в Safari и разрешите ему доступ к сайтам, на которых смотрите видео.
3. Нажмите **«Установить скрипт»** и сохраните `native-video-fullscreen.user.js` через приложение «Файлы» в выбранную папку Userscripts.
4. Вернитесь в Safari, откройте меню расширения Userscripts и обновите страницу с видео.

[Официальная инструкция Userscripts](https://github.com/quoid/userscripts#ios-ipados).

## Как пользоваться

Запустите видео и нажмите **⛶** в его верхнем правом углу. Если на странице несколько видео, скрипт отдаёт предпочтение тому, которое воспроизводится, а при равных условиях выбирает самое большое видимое видео. Кнопка сайта остаётся доступной.

Если кнопка не появилась, проверьте разрешения расширения. Для плеера, встроенного с другого домена, Userscripts нужен доступ и к адресу плеера. Скрипту требуется доступный HTML-элемент `<video>`, который Safari может открыть на весь экран. Наложенные сайтом элементы и субтитры, нарисованные поверх видео, могут не отображаться в системном режиме.

Скрипт не делает сетевых запросов и не сохраняет данные.

## Разработка

Весь код находится в `native-video-fullscreen.user.js`. Для проверки интерфейса откройте `tests/check.html` в настольном браузере и нажмите кнопку первого видео. Надпись `PASS` подтверждает, что скрипт выбрал нужное видео и вызвал полноэкранный API по нажатию. На стенде вызов системного плеера имитируется.
